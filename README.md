# Meesho Shopping Sales Dashboard | Power BI

## Project Overview
Developed an interactive shopping sales dashboard using Microsoft Power BI to analyze sales, profit, quantity, returns, and payment modes.

## Key Features
- **KPI Cards:** Total Sales, Profit, Quantity, and Records
- **Regional Analysis:** Sales and returns across West, East, Central, and South
- **Payment Mode Analysis:** COD, Online, and Cards
- **Sales & Profit Trends:** Comparison of sales and profit by quantity
- **Quantity Analysis:** Quantity distribution by region and returns

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Cleaning and Transformation
- Interactive Charts and KPI Cards

## Objective
To understand shopping sales performance, compare payment methods, analyze regional results, and identify useful business insights through interactive visualizations.
